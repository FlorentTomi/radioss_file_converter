# radioss_file_converter

- Help
```
radioss_file_converter.exe --help
radioss_file_converter.exe -h
```

- Conversion (supported output filetypes: *.json, *.vtk, *.csv)
```
radioss_file_converter.exe --input INPUT_FILE --output OUTPUT_FILE
radioss_file_converter.exe -i INPUT_FILE -o OUTPUT_FILE
```
