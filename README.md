# radioss_file_converter

- Help
```
radioss_file_converter.exe --help
radioss_file_converter.exe -h
```

- Conversion (supported output types: json, vtk, csv)
```
radioss_file_converter.exe --input INPUT_FILE --output OUTPUT_DIRECTORY -t FILE_TYPE
radioss_file_converter.exe -i INPUT_FILE -o OUTPUT_DIRECTORY -t FILE_TYPE
```
